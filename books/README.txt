إضافة سفر جديد = خطوتان:
1) ضع ملف JSON هنا (متعدد الإصحاحات {book, chapters:[...]} أو إصحاح واحد، بنفس صيغة أداة التوليد). انظر _example.json.
2) أضف سطراً في books/index.json:
   {"books":[{"id":"judith","title":"يهوديت","files":["judith.json"]}]}
   ويمكن لسفر واحد عدة ملفات: "files":["judith-1.json","judith-2.json"] وتُدمج الإصحاحات.
أسماء الملفات: حروف وأرقام وشرطات ونقاط فقط وتنتهي بـ .json. الإصحاح المعيب يُستبعد ويظهر سببه للخادم/المالك فقط.

وقت القراءة قبل الامتحان (اختياري لكل سفر): "readMinutes":3  (الافتراضي ٣ دقائق، والقيمة 0 تلغي الانتظار، والحد الأقصى ٦٠).
مثال: {"books":[{"id":"judith","title":"يهوديت","readMinutes":5,"files":["judith.json"]}]}

عدد أسئلة الامتحان (اختياري لكل سفر): "qCount":10  (يُسحب هذا العدد عشوائياً من أسئلة الإصحاح في كل محاولة؛ الافتراضي/٠ = كل الأسئلة).
مثال: {"books":[{"id":"judith","title":"يهوديت","qCount":10,"files":["judith.json"]}]}
