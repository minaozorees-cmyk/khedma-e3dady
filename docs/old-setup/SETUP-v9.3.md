# SETUP-v9.3 — زر "📤 إرسال النتيجة"

## الجديد
في شاشة نتيجة الامتحان زر **📤 إرسال النتيجة**. بالضغط عليه (بالتوازي):
1. **يرسل** النتائج المعلّقة للسيرفر فوراً (`sync.flush`) وينتظر النتيجة.
2. **يفحص** لو فيه نسخة جديدة من التطبيق (`update.checkUpdate`). لو لقى، بيظهر الشريط الذهبي "تحديث" (مش بيعيد تحميل الصفحة لوحده).

الرسائل: «تم إرسال نتيجتك ✅» / «مفيش نت… هتتبعت تلقائياً» / «لسه ما اتبعتتش… هتتحاول تلقائياً» + «التطبيق على آخر نسخة ✅» أو «فيه تحديث جديد».

**الإرسال التلقائي ما اتلمسش**: بيفضل شغّال (أول ما النت يرجع، وكل ٢ دقيقة، وعند فتح التطبيق). فلو المخدوم ماضغطش الزر، أو مفيش نت، النتيجة تتبعت لوحدها.

## الملفات
`js/update.js` (جديد)، `js/sync.js` (دالة `flush`)، `modules/books/index.js` (الزر)، `sw.js` (`v9.3` + `update.js` في الكاش).

## الاختبار
1. خلّص امتحان واضغط "إرسال النتيجة" والنت شغّال ← «تم إرسال نتيجتك ✅». تأكد إنها ظهرت في لوحة التميز عند الخادم.
2. اقفل النت وخلّص امتحان واضغط ← رسالة "مفيش نت"، افتح النت ← تتبعت لوحدها خلال دقيقتين.
3. ارفع نسخة بـ`VERSION` أعلى واضغط الزر ← «فيه تحديث جديد» ويظهر الشريط الذهبي.
