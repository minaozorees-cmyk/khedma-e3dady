# SETUP-v8.4 — الثيم الموحّد (شكل لوحة التميز v4 / ملوى شرق الموحّد v85)

## ما اتغيّر
| الملف | التغيير |
|---|---|
| `css/app.css` | أُعيدت كتابته بالكامل: ألوان داكنة `#08090B` + ذهبي `#E8C468`، كروت متدرّجة، أزرار، تبويبات، إحصائيات. وضع فاتح عبر `data-theme="light"`. أسماء الكلاسات كما هي فلم تتغيّر أي وحدة. |
| `index.html` | هيدر متدرّج، شريط علوي (☰ القائمة، اسم القسم، الاتصال، زر الثيم، دخول الخدام)، قائمة جانبية بدل الشريط السفلي، خلفية نجوم. |
| `js/ui.js` (جديد) | النجوم، تبديل الثيم، فتح/إغلاق القائمة الجانبية. |
| `js/router.js` | يكتب اسم القسم في الشريط العلوي ويخفي زر القائمة أثناء التسجيل/دخول الخدام. لا تغيير في منطق التوجيه. |
| `pages/servant.html` | حُقن فيه الثيم الموحّد (نفس كتلة `unified-skin` من اللوحة v4). |
| `pages/generator.html` | ثيم موحّد لواجهة الأداة فقط، **قوالب الامتحانات المولّدة لم تُمسّ**. |
| `css/fonts.css`, `fonts/README.txt` | إضافة خط Tajawal (خط النص في الثيم الجديد). |
| `sw.js` | `VERSION='v8.4'` + إضافة `js/ui.js` وخطوط Tajawal للكاش. |
| `manifest.json` | `background_color`/`theme_color` = `#08090B`. |

## ملاحظات
- الثيم محفوظ في `localStorage.theme` ومشترك بين التطبيق وصفحتي `servant`/`generator` (نفس الـ origin). زر ☀️/🌙 في الشريط العلوي.
- خط Tajawal وباقي الخطوط ما زالت **غير موجودة** في `fonts/` (انظر README). بدونها يستخدم الجهاز خط عربي من النظام.
- أيقونات PWA (`icons/`) لم تتغيّر؛ ألوانها القديمة (كحلي/ذهبي) ما زالت قريبة من الثيم.
- النجوم تتوقف تلقائياً في الوضع الفاتح، وعند إخفاء الصفحة، ومع تفضيل "تقليل الحركة".
- لم يتغيّر شيء في Supabase أو `schema.sql` أو `restore`.
