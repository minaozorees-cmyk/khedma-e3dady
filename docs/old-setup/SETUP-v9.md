# SETUP-v9 — لوحة المالك الكاملة (المرحلة ٨ب)

الباقي كله زي v8.4. التصميم (`css/app.css`, `index.html`, `ui.js`) **ما اتلمسش**. مفيش Edge Function جديدة.

## ما اتغيّر
| الملف | التغيير |
|---|---|
| `modules/owner/members.js` (**جديد**) | اللوحة: المخدومون + إحصائيات + سجل التدقيق. وحدة منفصلة عشان `modules/owner/index.js` (رفع الأسفار) يفضل شغّال زي ما هو. |
| `modules/registry.json` | تبويب جديد `🛡️ لوحة المالك` (للمالك فقط) قبل «إدارة الأسفار». |
| `sw.js` | `VERSION='v9'` + `modules/owner/members.js` في الكاش. |
| `supabase/schema.sql` | إضافات v9 (تحت) — آمن للتكرار. |

## ١) شغّل `supabase/schema.sql` كاملاً (SQL Editor)
اللي اتضاف/اتعدّل:
- `norm_name()` + تعديل `profiles_guard`: لما الخادم/المالك يغيّر `name`، الـtrigger بيحسب `name_norm` تلقائياً (نفس تطبيع `normName` في JS).
- `profiles_del_guard`: الحذف النهائي من التطبيق مرفوض لأي ملف مش محذوف ناعماً.
- `purge_expired_profiles()`: تنظيف يدوي (المالك فقط) للمحذوف من أكتر من ٣٠ يوم.
- `profile_activity` (view، للمالك فقط): آخر دخول وعدد الجلسات.
- `audit()` اتحدّثت: أفعال واضحة (`soft_delete/restore/update/hard_delete`) + إيميل الفاعل + **أسماء** الأعمدة المتغيّرة فقط (مفيش أرقام تليفونات في السجل).

⚠️ ملاحظة: الحذف النهائي بيمسح معاه نتائج المخدوم وجلساته (cascade).

## ٢) انشر وحدّث
ارفع الملفات على Netlify. الـService Worker نسخته `v9`، فاقفل التطبيق وافتحه (أو اضغط زر التحديث في الشريط) عشان النسخة الجديدة توصل.

## ٣) خطوات الاختبار (سجّل دخول كمالك: owner@test.com)
1. **المخدومون**: تبويب «🛡️ لوحة المالك» ظاهر في القائمة. القائمة بتعرض الاسم/الصف/الجنس/تاريخ التسجيل/آخر دخول. جرّب البحث بجزء من الاسم، وبجزء من رقم التليفون (٣ أرقام فأكتر).
2. **تعديل**: ✏️ تعديل ← غيّر الاسم أو الصف أو التليفون ← حفظ. تأكد في SQL Editor:
   `select name, name_norm from profiles where id = '...';` الـ`name_norm` لازم يتغيّر مع الاسم.
   (بعد تغيير الاسم، المخدوم هيحتاج الاسم **الجديد** + كوده لو استرجع حسابه على جهاز جديد.)
3. **حذف ناعم**: 🗑 حذف ← يختفي من «نشط» ويظهر في «محذوف» بعدّاد الأيام، ويختفي من لوحة التميز للخادم.
4. **استرجاع**: من تبويب «محذوف» ← ♻️ استرجاع ← يرجع نشط.
5. **حذف نهائي**: لملف محذوف من أقل من ٣٠ يوم: تأكيد أول + كتابة اسم المخدوم. للملف المنتهية مهلته: تأكيد واحد.
6. **تنظيف ٣٠ يوم** (اختبار): في SQL Editor خلّي ملف محذوف قديم:
   `update profiles set deleted_at = now() - interval '31 days' where id = '...';`
   ← ارجع للوحة ← تحديث ← يظهر كارت «تنظيف الحذف الناعم» ← «تنظيف الآن».
7. **إحصائيات**: نشط/محذوف/دخلوا آخر ٧ أيام/لم يدخلوا + توزيع الصفوف والجنس + آخر ١٥ دخول.
8. **سجل التدقيق**: لازم تلاقي أحداث الخطوات اللي فاتت (مين/عمل إيه/امتى) مع فلتر المخدومون/الأسفار وزر السابق/التالي (٢٠ حدث في الصفحة).
9. **صلاحيات** (اختياري): ادخل كخادم ← تبويب «لوحة المالك» مش ظاهر. ولو حاولت من Console تعمل PATCH على `deleted_at` كخادم ← `42501` (`profiles_guard`).
